# SubMeld · 订融

私人节点转换与订阅工具。把节点整理清楚，把转换结果交代清楚。

当前版本 `0.0.0` 仅完成可运行工程骨架：Vue 页面、Hono 服务、真实健康状态、构建及检查入口。P1～P4 均未完成；目前没有登录、节点转换、数据库、私人订阅或远端抓取功能。

## 环境与启动

- Node.js `24.6.0`（`.node-version` 固定的开发基线；支持 Node 24 系列从此补丁起）。
- pnpm `10.33.2`（`packageManager` 固定）。
- 单个根包，依赖精确锁定；无需全局安装 Vite、TypeScript 或 Hono。

在项目根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://127.0.0.1:5173>。Vite 和 Hono 分别绑定 `127.0.0.1:5173`、`127.0.0.1:3000`；前端通过同源 `/healthz` 代理检查服务连接。端口占用会报错，先停止占用该端口的进程再启动。按 Ctrl+C 结束开发进程。

运行构建产物前，先停止开发服务，避免占用同一端口：

```sh
pnpm build
pnpm start
```

打开 <http://127.0.0.1:3000>。Hono 同时提供构建后的网页、静态资源与健康接口，构建产物位于 `dist/`。

本次骨架固定监听回环地址，仅用于本地开发及验证；生产配置、认证、持久化和单容器部署随 P1 一起实现。当前不需要环境变量或数据目录。

## 检查命令

| 命令                | 用途                                     |
| ------------------- | ---------------------------------------- |
| `pnpm dev`          | 同时启动前后端开发服务                   |
| `pnpm build`        | 构建网页并编译服务端                     |
| `pnpm start`        | 运行构建后的单个应用                     |
| `pnpm format`       | 格式化工程文件，保留原始文档和许可证正文 |
| `pnpm format:check` | 只检查格式                               |
| `pnpm lint`         | ESLint 检查                              |
| `pnpm typecheck`    | 检查 Vue、服务端和构建配置类型           |
| `pnpm test`         | 先构建，再执行真实 HTTP 集成测试         |
| `pnpm check`        | 格式、lint、类型、构建和集成测试         |

脚本兼容 Windows 和 Linux，不依赖 shell 环境变量赋值或 Unix 文件命令。集成测试使用 Node.js 自带测试运行器，在回环随机端口验证构建产物，并自动关闭服务。测试覆盖首页及 JS/CSS、健康接口、未知 API／订阅路径的 JSON 404；这些不是 P1 业务验收结果。

## 代码与接口

```text
web/       Vue 页面与样式
server/    Hono 应用和 Node.js 启动入口
tests/     构建产物的 HTTP 集成测试
docs/      保留的项目文档
dist/      生成的网页和服务端，不提交 Git
```

`GET /healthz` 返回 `200 application/json`、`Cache-Control: no-store` 和 `{"status":"ok"}`，仅表示进程存活。未知路径返回 `404` 和 `{"code":"NOT_FOUND","message":"请求的资源不存在。"}`；API 和订阅路径不回退到网页。`HEAD` 使用对应 GET 状态和响应头，但不返回正文。

未来按 P1 → P2 → P3 → P4 推进：转换工作台 → 节点保存与三内核配置 → 私人订阅 → 远端来源与自动更新。SQLite、转换 Worker、Sub-Store 适配和容器配置在实际功能需要时引入；当前不预建业务表、数据模型、假接口或上游锁文件。
